Yumly – приложение за рецепти и хранителни планове

Yumly е уеб приложение за управление на рецепти и генериране на персонализирани хранителни планове чрез използване на изкуствен интелект.

Основни функционалности:
Регистрация и вход на потребители
Създаване, редактиране и изтриване на рецепти
Любими рецепти
Персонален здравен профил
Генериране на седмичен хранителен план
Изчисляване на хранителни стойности
Проверка за диетични ограничения
Автоматичен превод на рецепти
Административен панел

Използвани технологии:

Frontend:
React
TypeScript
Tailwind CSS
React Router
Context API

Backend:
Node.js
Express
TypeScript
MongoDB / Mongoose
JWT Authentication

Изкуствен интелект:
Приложението използва Groq API (LLaMA модел) за:

Генериране на хранителни планове
Анализ на диетични ограничения
Изчисляване на хранителни стойности
Генериране на кулинарни препоръки
Превод на рецепти

Архитектура:
Frontend – потребителски интерфейс
Backend – REST API
MongoDB – база данни
Groq AI – интелигентни функционалности
